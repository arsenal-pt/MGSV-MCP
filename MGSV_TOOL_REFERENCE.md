# MGSV tools and MCP support reference

Reference snapshot checked on **2026-10-11** against the live `mgsv-modding` server **0.3.1**. The catalog contains **211 entries**, including tool pages, converter integrations, repository references/forks, suite components, guides, downloads and discovery lists. It is not a list of 211 separate installed programs.

**20 converter integrations are installed and callable. FvTwool and Ninja Ripper 1.7.1 are downloaded GUI packages with no automated GUI adapter.** Other entries provide varying levels of documentation, linked references or source browsing.

## How to read MCP support

| Label | What the MCP does |
|---|---|
| Run | Copies inputs into a workbench job, prepares the converter command, executes it, and returns logs plus changed-file hashes. |
| Downloaded GUI | Tracks the downloaded package and executable presence. Instructions are available, but the MCP does not operate its GUI. |
| Docs | Searches and retrieves indexed wiki/publisher text. Reads catalogued repository code and release information on demand where available. |
| Link or Reference | Provides a source link, surrounding wiki instructions or curated notes. The external site is not necessarily mirrored. |
| Discovery | Retains a repository/profile/topic listing. A listing does not establish compatibility, completeness or recommendation. |

A runnable converter is not a guarantee that every possible file/version has been tested. Conversion results require suitable round-trip checks, and game behavior requires in-game verification. Workbench staging is not an operating-system sandbox. These commands do not install mods or write to the live game directory.
