# Project roles and contributions

- **arsenal-pt:** project creator, owner, maintainer and human direction/testing.
- **OpenAI Codex:** AI implementation contributor/tool used to produce the original server, tests, setup and documentation under arsenal-pt's direction. This does not mean OpenAI owns, endorses or maintains the project.
- **Community tool/document authors:** their upstream authorship and terms remain intact; see CREDITS.md.

GitHub's Contributors display follows commit-account attribution. It does not establish who manually wrote a line or erase human direction, tests or documentation. AI-authored publication commits explicitly disclose the implementation role. Future human source/docs/model work should be credited in commits and pull requests under the contributor's chosen identity.
